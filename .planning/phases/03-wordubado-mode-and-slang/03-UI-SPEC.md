# Phase 3 — UI Design Contract

> Visual and interaction contract for Wordubado mode. Extends `02-UI-SPEC.md` (tokens, typography, spacing, motion, accessibility rules all still apply); only deltas are specified here. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 03-CONTEXT.md D-08..D-18, 02-UI-SPEC.md, existing `src/styles/tokens.css` and `game.css`.
> Items marked `[DEFAULT — owner may change]` were chosen by the researcher, not by the owner.

## Scope

In scope: header mode switch ("Wordubado"), (i) info button, two-row header layout, Wordubado mode accent token, a reusable modal dialog (used for the (i) popup and the switch-confirm), copy for both, focus and keyboard rules for the dialog.

Out of scope: help / stats / settings buttons (stay hidden, `.header-actions` slot kept, D-13), dark and colour-blind palettes (Phase 7; a suggested dark value is noted only so the token is ready), persistence of mode or "popup seen" (Phase 4), definitions (Phase 6). Tile, key, banner and toast styling do not change in Wordubado (D-15).

## Spacing Scale

Unchanged from Phase 2 (`--space-1..7`: 4, 8, 16, 32, 24, 48, 64). New usages:

| Token | Usage in Phase 3 |
|-------|------------------|
| `--space-1` (4px) | Gap between switch group and (i) button; length-picker segment gap below 400 px |
| `--space-2` (8px) | Gap between header rows; gap between switch label and track; dialog button gap |
| `--space-3` (16px) | Dialog body to button row gap |
| `--space-5` (24px) | Dialog inner padding |

Exceptions (intentional):

- Switch track is 36 x 22 px with a 16 px knob (component sizes, not spacing tokens). The whole switch button (label + track) is the hit target, 40 px high (44 px at 400 px and wider).
- (i) button: 32 px visual circle, hit area 40 x 40 (44 x 44 at 400 px and wider) via padding. Targets under 44 px below 400 px follow the Phase 2 WCAG 2.5.8 exception (24 px minimum met).
- Below 400 px the length-picker segments drop to `min-width: 36px` and track gap to 4 px (was 44 / 8) so row 2 fits 288 px. This amends the Phase 2 picker size at that width only.

## Color

Dominant, secondary, destructive and tile/key tokens unchanged (`--color-bg #fbfaf7`, `--color-surface #f0eee8`, `--color-error #c97b7b`, tile tokens).

### Wordubado mode accent (new)

Not `--color-accent` (sage `#a9c4b0` styles the selected length segment, correct tiles/keys and the "Play again" button; reusing it would make Wordubado indistinguishable and would mix semantics). A dedicated soft lilac pair:

| Token | Value | Notes |
|-------|-------|-------|
| `--color-wordubado` | `#7a5fb0` | Constant, defined on `:root`. Used for the switch "on" track. Contrast on `--color-bg` about 4.9:1 (meets 4.5:1 text and 3:1 non-text). Knob `#fbfaf7` on this track about 4.9:1. |
| `--color-mode` | Normal: `var(--color-text)`; Wordubado: `var(--color-wordubado)` | Semantic token the title reads. Set with `[data-mode='wordubado'] { --color-mode: var(--color-wordubado); }`. Put `data-mode="normal|wordubado"` on the `.app` root element (not on `body`) driven from the store `mode`. |

Phase 7 hint (not implemented now): dark theme override `--color-wordubado: #b7a3e6` (about 7:1 on a `#1f2128`-class background), knob `#1f2128`.

`[DEFAULT — owner may change]`: lilac hue. Any hue other than sage/yellow/gray (tile roles) and the error rose works; it must keep 4.5:1 on `#fbfaf7`.

### Accent usage after Phase 3

60 / 30 / 10 split unchanged. Mode accent is a small extra (under 2% of surface).

Sage accent `--color-accent` reserved for (exhaustive, extends Phase 2 list):
1. Correct tiles and correct keys
2. Selected length-picker segment
3. "Play again" button fill
4. Primary button fill inside dialogs ("Got it", "Start new game")
5. Keyboard focus ring uses `--color-focus` (unchanged)

`--color-wordubado` reserved for (exhaustive):
1. Site title text while mode is Wordubado
2. Switch track fill while on
3. (i) button icon stroke while mode is Wordubado (in Normal it is `--color-text`; `--color-muted` is only about 3.8:1)

Never use the mode accent for tiles, keys, banners, toasts, borders on empty tiles or dialog buttons.

Colour is never the only mode cue: the switch position (knob left/right) and `aria-checked` also convey it.

### Switch colours

| State | Track | Border | Knob |
|-------|-------|--------|------|
| Off (Normal) | `--color-surface` | 1px `--color-muted` (about 3.8:1, meets 3:1 non-text) | `--color-muted` fill, 16 px circle at left |
| On (Wordubado) | `--color-wordubado` | 1px `--color-wordubado` | `--color-bg`, knob at right |
| Disabled (revealing) | same as current state, `opacity: 0.5` | | `aria-disabled="true"`, `cursor: default`, click is a no-op |

Focus ring: `outline: 2px solid var(--color-focus); outline-offset: 2px` on `:focus-visible` (same as all controls).

### Dialog colours

Scrim `rgba(43, 45, 51, 0.32)`. Card fill `--color-bg`, radius `--radius-card` (20px), shadow `--shadow-toast` (the only existing soft shadow allowed on overlays; no new shadow). Primary button: sage accent fill, `--color-text` text, same as Play again (44 px high, min-width 128 px, pill, `--shadow-button`). Secondary button: `--color-surface` fill, `--color-text` text, same size, no shadow. No red anywhere: the confirm is a soft stop, not a destructive error.

## Layout and Components

### Header (replaces the Phase 2 single-row layout)

Two rows at every width. Row 1 is title (plus the reserved empty `.header-actions` slot, `display: none` until Phase 4/5/7). Row 2 is the mode group on the left and the length picker on the right.

```
>= 400 px:   Unlimited Wordle                  [reserved actions slot]
             Wordubado (o-)  (i)               [ 4 | 5 | 6 ]

< 400 px:          Unlimited Wordle   (centred)
             Wordubado (o-) (i)   [ 4 | 5 | 6 ]
```

- Row 1 height 32 px, row gap `--space-2` (8 px), row 2 height 40 px (picker 40, switch 40, (i) 40). Header total height 80 px at all widths (was 48 px at 400+; 80 px at under 400, unchanged). Row 2 uses `display: flex; justify-content: space-between; align-items: center; width: 100%`.
- Mode group = switch button then (i) button, 4 px (`--space-1`) apart, left aligned.
- Fit proof at 320 px (288 px content): switch about 74 (label) + 8 + 36 (track) = 118, gap 4, (i) 40, row gap, picker 3 x 36 + 2 x 4 = 116. Total 118 + 4 + 40 + 116 = 278 px with 10 px slack; `justify-content: space-between` absorbs it. Playwright must assert no horizontal overflow and no wrapping at 320 px wide.
- Header height impact at 320 x 568: 80 px (unchanged from the Phase 2 budget, which already assumed 80). No change to the grid fit proof.
- Short viewports (`max-height: 540px`): keep two rows but compact: title 14 px/600 at row height 24 px, row 2 36 px high (switch, (i) and picker segments), gap 4 px, total 64 px. Phase 2's 48 px single row no longer applies. Because header grows 16 px, the tile floor in this media query drops from 36 px to 32 px (`--tile-min: 32px`); 6 x 7 grid = 7 x 32 + 6 x 4 = 248 px; budget at 320 x 500: 64 + 8 + 248 + 8 + 124 = 452 px, fits with 48 px slack. Verify no vertical scroll at 320 x 500, 320 x 568, 320 x 640.
- Title colour reads `var(--color-mode)`; add `transition: color 160ms ease` (removed under reduced motion).
- Title text stays "Unlimited Wordle" in both modes (the mode is shown by tint, the switch, and nothing else; no suffix).

### Mode switch

- Element: `<button type="button" role="switch" aria-checked="true|false">` with visible text "Wordubado" (Label 14/600, `--color-text`) followed by the track. Accessible name is "Wordubado" (from content). Space and Enter toggle (native button behaviour). Not a checkbox, not a segmented control (D-12).
- Knob slides 14 px in 160 ms (`--ease-soft`); under reduced motion it jumps instantly with no transition.
- Toggling: if D-09 "in progress" (at least one submitted guess, status not won/lost) the dialog opens first and the switch keeps its old position until confirmed. Otherwise the new game starts immediately. After a toggle that changes mode, focus stays on the switch.
- Disabled while `status === 'revealing'` (`aria-disabled`, no-op), same as the length picker.
- Switching mode starts a new game at the current length in the new mode; the loading state from Phase 2 applies (empty grid, disabled keyboard, "Loading words..." after 400 ms).

### (i) button

- `<button type="button" aria-label="About Wordubado" aria-haspopup="dialog">`, 32 px circle visual with the info icon centred (18 px), transparent fill, icon colour `--color-text` in Normal and `--color-wordubado` in Wordubado, hover fill `--color-surface`. Always visible, enabled even while revealing (D-17). Opens the info dialog.

### Reusable dialog (Dialog component, D-10)

One component, two uses. Build it generic (title, body, actions as props or children) so Phase 4 modals reuse or replace it.

- Structure: fixed full-screen scrim; centred card, `width: min(360px, calc(100vw - 32px))`, padding `--space-5` (24 px), vertical flex, gap `--space-3` (16 px). Heading 20/600 left aligned, body 16/400 (line-height 1.5), buttons row right aligned (`justify-content: flex-end`, gap 8 px); under 400 px the buttons stack full width, primary on top.
- Semantics: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` heading id, `aria-describedby` body id. Render with a portal to `document.body`; set the app root `inert` (or `aria-hidden`) while open.
- Behaviour: focus moves into the dialog on open; Tab and Shift+Tab are trapped inside; Esc closes (info: close; confirm: cancel); clicking the scrim does the same as Esc; on close, focus returns to the element that opened it (the (i) button, switch, or the length segment that was pressed). If the info popup auto-opens after a confirmed mode switch, its return target is the switch.
- Initial focus: info dialog focuses "Got it". Confirm dialog focuses the **cancel** button "Keep playing" (safer default for a game-ending action).
- Game input while a dialog is open: the physical-keyboard `keydown` handler ignores all keys; on-screen keyboard is `inert` with the rest of the app; no reveal can be started.
- Motion: opens with opacity 0 to 1 and scale 0.98 to 1 over 160 ms; closes with opacity to 0 over 120 ms. Reduced motion: opacity only, 120 ms open, instant close.
- Only one dialog at a time. Sequence for the first Wordubado switch with a game in progress: confirm dialog, then on confirm the info popup (D-16). Cancelling the confirm shows no popup.

### (i) popup trigger rules (D-16)

- Opens on (i) tap, always.
- Opens automatically once per page session the first time Wordubado is turned on (in-memory flag, resets on reload until Phase 4). Auto-open happens after the new game is started and the mode is already switched; it does not auto-open when turning Wordubado off.

## Interaction Rules

- Mode or length change, no guesses submitted (even with letters typed), or game finished: switch immediately, no prompt.
- Mode or length change, at least one guess submitted, game not finished: open the confirm dialog. "Start new game" starts the new game in the target mode/length and closes the dialog. "Keep playing", Esc or scrim click: close, nothing changes, focus returns to the control pressed, switch/picker visuals stay on their old value.
- Mode or length change while `revealing`: blocked (no-op), controls show `aria-disabled`.
- Defaults on load: Normal, default length from Phase 2. Not persisted (D-08, D-11).
- Play again keeps the current mode.
- Tab order: switch, (i), length picker, keyboard keys, Play again.
- Reduced motion: switch knob, title tint, dialog scale all lose transitions as described; nothing else new animates.

## Accessibility (additions)

- Switch: `role="switch"`, `aria-checked`, name "Wordubado", keyboard operable by Space and Enter.
- (i): `aria-haspopup="dialog"`, name "About Wordubado".
- Dialog: modal semantics, focus trap, Esc, focus return, background inert (see Layout).
- Contrast: title tint `#7a5fb0` on `#fbfaf7` about 4.9:1; switch off-state border `--color-muted` about 3.8:1 (non-text 3:1); (i) icon `--color-text` about 13:1; dialog text `--color-text` on `--color-bg` about 13:1; dialog buttons `--color-text` on sage about 7:1 and on surface about 12:1. Run an axe check on the page in both modes and with each dialog open.
- Touch targets: switch 40/44 high, (i) 40/44, dialog buttons 44.
