<objective>
User story slice: **As a** new player, **I want** How-to-play to greet me on my first visit and be one click away afterwards, **so that** I understand tile colours, modes and streaks without leaving the game.

Header order decision (pattern-mapper flag 1, resolved): HelpButton is the FIRST child of .header-actions, so the DOM and Tab order is Help, Day Streak chip (only when the streak is above 0), Statistics, Settings. This satisfies CONTEXT D-06 ("first in .header-actions, left of Stats and Settings") and UI-SPEC ("first child of .header-actions; order Help, Stats, Settings"; the chip is not mentioned there and stays where it already is, left of Stats).

Auto-open call sites (resolves RESEARCH A5, verified): checkStreaks is synchronous and sets pendingRestore/breakNotice in one set; resume() runs loadBoard/startGame whose dialog: null set happens synchronously before their first await, so calling maybeOpenHelp after both in main.tsx cannot be undone by the load. Calls go in boot code and store actions, never in React effects (StrictMode).

Purpose: UI-04 and the help-button part of UI-05 (D-05..D-09).
Output: modal + copy (Task 1), help button + header + CSS (Task 2), boot and action wiring (Task 3); help.spec and layout.spec green.
</objective>
