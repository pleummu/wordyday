<objective>
User story slice: **As a** keyboard-only or low-vision player, **I want** every part of the game, every dialog and every theme to work and stay readable without a mouse, **so that** I can play the whole game my way.

This is the D-14 audit with E2E proof, plus the fixes it surfaces. Two findings are already known from reading the code and are fixed here:
1. Modal's Tab trap takes the first/last of all enabled buttons; with roving tabindex (Settings theme radios from 07-06, existing Statistics tabs) the first or last collected button can be tabindex -1, so Shift+Tab or Tab escapes the dialog. Fix: only count buttons with tabIndex >= 0.
2. Header buttons carry data-own-enter, so after a dialog closes and focus returns to its opener, typing a word and pressing Enter re-opens the dialog instead of submitting. Fix: when an accepted letter or Backspace is typed while focus sits on an element outside any dialog, blur it, so the next Enter plays.

Purpose: UI-08 and the axe proof for UI-02/UI-03.
Output: keyboard.spec, Modal and physical-keyboard fixes with unit tests, a11y-themes.spec, token tuning.
</objective>
