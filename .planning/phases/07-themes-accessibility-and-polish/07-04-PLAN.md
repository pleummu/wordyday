<objective>
User story slice: **As a** player whose device is in dark mode, **I want** the game to open in a soft dark theme straight away, with no white flash, and to follow my OS when it changes, **so that** it is comfortable at night.

The Light/Dark/System picker that pins the theme arrives in 07-06; this slice is the whole dark experience for System players (the default, D-01), end to end: tokens, pre-paint script, live follow.

No-flash mechanism (Claude's discretion, decided): a classic inline script in the head reads the existing versioned save doc (key unlimited-wordle, SAVE_KEY) inside try/catch, whitelists the values and sets data-theme (resolved light or dark) and data-palette on <html> before CSS paints. No second storage key: the versioned doc stays the single source of truth (RESEARCH Pattern 1). The app then re-applies from the store via startAppearance, started once outside React like startStreakWatch.

Purpose: UI-02 (D-01, D-02).
Output: failing theme.spec, dark tokens, head script, appearance.ts with unit tests, boot wiring.
</objective>
