## Phase Goal

**As a** player, **I want to** see accurate Win Streaks for each Board, one global Day Streak protected by up to 3 Restores a month, and full statistics for each mode and length, **so that** I can track my progress and have a reason to come back every day.

<objective>
User story slice: **As a** player, **I want to** see my Win Streak for this Board in the result banner, **so that** I know how many games in a row I have won here.

This plan introduces the complete v2 saved document (every Phase 5 persisted field, so the version bumps only once), records each finished game into per-Board running counters at submit time, and shows the Win Streak line in the existing banner. Task 2 defines the v2 document and recordResult, Task 3 wires recording and the banner line, and Task 4 hardens the upgrade path (D-18 migration tests, WR-03, IN-01).

Purpose: STRK-01 plus the storage part of QA-02; the foundation the Stats modal, Day Streak and Restore slices read from.
Output: `src/logic/stats.ts`, v2 `src/logic/save.ts`, store finish recording, banner line, `e2e/streaks.spec.ts`.
</objective>
