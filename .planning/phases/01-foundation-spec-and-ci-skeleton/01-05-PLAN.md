## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub repo -> Vercel | Vercel GitHub App reads the repo and builds every pushed branch |
| Vercel CDN -> public internet | Production URL is public; previews are behind Vercel Deployment Protection by default |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14 | Information disclosure | Vercel tokens / secrets | mitigate | No Vercel token stored in GitHub, no deploy step in Actions (D-14); Vercel project has no environment variables |
| T-01-15 | Elevation of privilege | Vercel GitHub App scope | mitigate | Owner grants the app access to the single repo `pleummu/wordyday` only ("Only select repositories") |
| T-01-16 | Tampering | deploys of failing code | accept | Until Phase 8 branch protection (D-15), a red CI does not block Vercel; owner is told this in the checkpoint; site has no data or users yet |
| T-01-17 | Spoofing | fork PR previews | accept | Vercel requires owner authorisation for fork PR deployments by default; repo is private |
</threat_model>
