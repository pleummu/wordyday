## Phase Goal

**As a** player, **I want to** keep a separate saved game on each of the six Boards that survives refreshes, mode and length switches and broken storage, with a fair Give Up and a way to reset everything, **so that** I can come back to any game later without ever losing progress.

<objective>
Make every write from this tab a truthful, complete document: games carry ids, the old game is captured (not re-broadcast as playing, not dropped) while the next game loads, forfeits are stored as finished first, and deferred external documents die with the game they were deferred for.

Closes WR-01 and WR-03, and the "do not broadcast a board-less loading document" half of CR-02. The receiving side (per-Board merge in applyExternal) is 04-11.
Purpose: SAVE-08 (tabs only ever see real game states) and SAVE-09 (a reset cannot be undone by a stale document).
Output: store changes plus unit tests that record every storage write.
</objective>
