<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other tab -> this tab | `storage` events carry text written by another same-origin context (possibly an older or newer build) |
| browser -> storage API | Access can throw (blocked) or writes can fail (quota) |
| network -> chunk load | Word-list chunk may fail to load |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-20 | Spoofing | sync.ts storage listener | mitigate | Ignore events whose `storageArea` is not localStorage or whose key is not `unlimited-wordle` (null allowed for clear) |
| T-04-21 | Tampering | applyExternal | mitigate | External text goes through `storage.read` (same parse/migrate/guard as boot); invalid text is ignored, never merged, never backed up |
| T-04-22 | Denial of service | tab echo loop | mitigate | `markSeen(raw)` before applying plus adapter write dedupe; fixed key order in `docFromState`/`validateSave`; test asserts no identical write-back |
| T-04-23 | Repudiation (double count) | sync of finished games | mitigate | applyExternal sets status from storage and never calls `finishGame`; test spies the seam |
| T-04-24 | Denial of service | blocked/full storage | mitigate | Adapter never throws; one 4 s toast; Settings storage-off line; E2E plays full games with throwing storage |
| T-04-25 | Denial of service | chunk retry hang | mitigate | Offline rejects immediately; online reload rejects after 3 s if blocked |
| T-04-26 | Integrity | last-write-wins race between two tabs writing different Boards within event latency | accept | Window is milliseconds; whole-document replace converges (research A6) |
</threat_model>
