## Phase Goal

**As a** player, **I want to** get a satisfying result screen when a game ends, with the answer, my stats, a definition and a way to share, **so that** I can replay, learn the word and show my result to friends.

<objective>
User story slice: **As a** player, **I want** everything that already worked before the Result modal (playing, Boards, saves, other-tab sync, streaks, Give Up, Forfeit, Statistics, Restores) to keep working now that a modal opens at the end of each game, **so that** the new result screen costs me nothing I had.

Purpose: closes the regression gap opened by 06-01 (auto-open modal) and 06-02 (slim banner copy). Split out of 06-02 so each plan stays at two to three tasks. Runs in Wave 3 next to 06-03 (no shared files).
Output: the ten legacy E2E specs migrated; the full Playwright suite green.
</objective>
