Contracts the UI (02-07) must satisfy, used by these tests:
- Grid cells: role "gridcell", names "Row {r}, column {c}, empty" | "Row {r}, column {c}, letter {L}" | "Row {r}, column {c}, letter {L}, {correct|present|absent}"
- On-screen keyboard: button named "Enter" (disabled while loading); it is removed when the game ends (banner replaces the keyboard)
- Length picker: role "radio" with names "4 letters", "5 letters", "6 letters"
- Banner: text "You got it in {n} of {max}" + "Ready for another?" on a win; "The word was {ANSWER}" + "Better luck next time." on a loss; button "Play again", focused when the banner appears

Test hook (implemented in 02-06 by src/state/testHook.ts):
- globalThis.__WORDLE_TEST__ = { answers: { 4?: string, 5?: string, 6?: string } }, read when a game starts; ignored unless the word is in that length's Guess Pool
