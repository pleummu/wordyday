## Phase Goal

**As a** player, **I want to** play a complete, correctly scored Normal game at 4, 5 or 6 letters in the browser, **so that** I can enjoy endless Wordle at the length I choose.

<objective>
Build the game engine that the UI in 02-07 binds to: the lazy per-length pool loader and the single-game Zustand store with its reveal lock. The failing E2E from 02-05 stays red until 02-07; this plan proves the engine with unit tests.

Purpose: The store is where correctness and StrictMode safety live (answer picked in actions, idempotent reveal finish, stale-load guard). Its shape (one game object plus actions) wraps into `boards[key]` in Phase 4.
Output: `wordData.ts`, `gameStore.ts` with tests, copy constants, test hook.
Git: branch `phase-02/playable-normal-game`; pathspec-limited `git add` only.
</objective>

src/state/gameStore.ts
- export type GameStatus = 'loading' | 'error' | 'playing' | 'revealing' | 'won' | 'lost'
- export type Row = { letters: string; states: TileState[] }
- export type Toast = { id: number; text: string; kind: 'error' | 'info' }
- export type SubmitResult = 'ok' | 'short' | 'invalid' | 'blocked'
- export type GameDeps = { loadPools: (length: WordLength) => Promise<Pools>; rng: () => number; prefersReducedMotion: () => boolean; setTimer: (fn: () => void, ms: number) => unknown }
- export type GameState = {
    length: WordLength; answer: string; rows: Row[]; current: string; status: GameStatus;
    keyStates: KeyStates; toast: Toast | null; shakeId: number; shakeRow: number; pools: Pools | null; loadToken: number;
    startGame(length: WordLength): Promise<void>; selectLength(length: WordLength): void; playAgain(): void; retryLoad(): void;
    typeLetter(letter: string): void; backspace(): void; submit(): SubmitResult; finishReveal(): void; dismissToast(id: number): void }
    // shakeId increments on every rejection (re-triggers the animation); shakeRow is the 0-based row index that was rejected, -1 when none.
    // The UI shakes a row only when shakeRow === rows.length (the active row), so later rows never inherit an old shake.
- export function revealDurationMs(length: WordLength, reduced: boolean): number   // reduced ? 150 : (length - 1) * 300 + 500
- export function createGameStore(deps: GameDeps)   // returns a Zustand `create<GameState>()(...)` hook
- export const useGameStore = createGameStore(defaultDeps)   // defaultDeps: loadPools from wordData, Math.random, matchMedia('(prefers-reduced-motion: reduce)'), window.setTimeout
